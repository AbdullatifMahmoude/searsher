# تطبيق دليل كشف رواتب أعضاء هيئة التدريس 📱💼

تطبيق ويب عصري (Front-End Only) مصمم خصيصاً للاستخدام السلس عبر الهاتف المحمول، للبحث والتعديل والإضافة في كشف رواتب السادة أعضاء هيئة التدريس المستخرج من شيت جوجل.

---

## ✨ المميزات الرئيسية:

1. **تصميم Mobile-First بالكامل**:
   - واجهة عربية RTL بتصميم فاخر وتدرجات وألوان متناسقة (خط Cairo العربي).
   - تجربة استخدام شبيهة بتطبيقات الهواتف الأصلية (Bottom Sheet للنماذج، بطاقات تفاعلية، أزرار لمس مريحة).
   - دعم كامل للوضعين (الليلي Dark Mode والنهاري Light Mode).

2. **بحث ذكي وفوري (Smart & Tolerant Search)**:
   - يبحث بالاسم، الوظيفة، أو رقم المسلسل (م).
   - تجاهل الفروق الشائعة في الكتابة (الهمزات: أ/إ/آ/ا، التاء المربوطة والهاء، الياء والألف المقصورة، والأرقام العربية والإنجليزية).
   - تمييز وإبراز النصوص المطابقة (Highlighting).

3. **تصفية سريعة وترتيب متقدم**:
   - تصنيف تلقائي بحسب الوظيفة (عميد الكلية، وكيل الكلية، أستاذ، ...).
   - خيارات ترتيب متعددة (حسب المسلسل، أبجدياً، أو بحسب المرتب من الأعلى للأقل والعكس).

4. **تعديل وعرض تفاصيل كل شخص**:
   - النقر على أي بطاقة يفتح نافذة سفلية تعرض كافة التفاصيل وتمكنك من تعديل أي بيان وحفظه فوراً.
   - إمكانية حذف أي سجل أو نسخ بيانات الشخص بضغطة زر.

5. **حساب تلقائي ذكي**:
   - عند كتابة "المرتب قبل 7/1" و"العلاوة" و"الـ 10%"، يقوم التطبيق تلقائياً بحساب وتحديث المرتب النهائي، مع إمكانية التبديل للوضع اليدوي.

6. **إضافة أشخاص جدد (+)**:
   - زر عائم (FAB) لإضافة أشخاص جدد مع توليد تلقائي للرقم المسلسل التالي.

7. **تخزين تلقائي محلي (LocalStorage)**:
   - جميع الإضافات والتعديلات تُحفظ فوراً على جهازك وتبقى محفوظة حتى بعد إغلاق المتصفح أو إعادة تشغيل الهاتف.

8. **تصدير واستيراد البيانات**:
   - تصدير فوري إلى ملف Excel (`.xlsx`) أو ملف `CSV`.
   - استيراد أي ملف Excel أو CSV لتحديث الكشف بالكامل في ثوانٍ.
   - خيار "استعادة البيانات الأصلية" من شيت جوجل في أي وقت.
   - إمكانية طباعة أو حفظ التقرير بصيغة PDF.

## 🚀 كيفية التشغيل والفتح على الهاتف:

### الطريقة 1: الفتح على الهاتف عبر شبكة الـ Wi-Fi المحلية
إذا كان الهاتف والكمبيوتر متصلين بنفس شبكة الـ Wi-Fi، يمكنك فتح المتصفح على هاتفك وكتابة الرابط:
```
http://192.168.1.12:5050
```
*(أو استبدل `192.168.1.12` بعنوان الـ IP الخاص بجهازك إذا تغير)*.

### الطريقة 2: فتح الملف مباشرة
يمكنك فتح ملف `index.html` في أي متصفح (Chrome, Safari, Edge) سواء على الكمبيوتر أو بعد نقله للهاتف وسيعمل بكامل وظائفه وبدون الحاجة لإنترنت.

### الطريقة 3: رفعه على الإنترنت مجاناً (GitHub Pages أو Vercel / Netlify)
المشروع عبارة عن فرونت فقط، يمكنك سحب المجلد بالكامل ورفعه على:
- **Netlify Drop** (سحب وإفلات في ثانية واحدة ويكون متاحاً برابط عام)
- **Vercel**
- **GitHub Pages**
